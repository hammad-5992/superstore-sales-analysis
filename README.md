# Superstore Sales Analysis

Exploratory data analysis of a retail superstore dataset using Python and pandas,
examining sales and profit trends across regions, categories, and customers.

## Dataset
Source: [Superstore Dataset, Kaggle](link)
9,994 rows, order-level sales data from a US retail superstore (2014-2017).

## What I did
- Cleaned the data: dropped unused columns, converted dates, checked for duplicates
- Engineered new columns: Year, Month, Profit Margin, Shipping Days
- Analyzed sales and profit by region, category/sub-category, customer, and time
- Investigated the relationship between discount level and profitability
